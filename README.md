# ICC_World_Cup-_2023_Analysis
📌 Problem Statement

Cricket World Cup tournaments generate massive match-level and player-level data. However, raw data alone does not provide actionable insights.

This project aims to analyze World Cup performance trends to uncover team dominance, player contributions, and match-winning factors using data analytics.

🎯 Objectives

Perform Exploratory Data Analysis (EDA)

Identify key performance indicators (KPIs)

Analyze match outcomes and trends

Generate meaningful visualizations

Provide actionable insights

🗂️ Dataset Description

The project uses the following CSV files:

batting_summary.csv → Contains batsman-level performance (runs, balls, strike rate, boundaries, dismissal)

bowling_summary.csv → Contains bowler statistics (overs, wickets, economy, runs conceded)

match_schedule_results.csv → Match details (teams, venue, date, winner, scorecard link)

world_cup_players_info.csv → Player metadata (team, role, batting style, bowling style, description)

📊 Key Analysis Performed
1. Team Performance Analysis

Matches played vs wins

Win percentage comparison

👉 Insight: Consistent teams maintain higher win ratios.

2. Toss Impact Analysis

Toss winner vs match winner

👉 Insight: Toss has limited influence on final outcomes.

3. Batting Analysis

Top scorers

Strike rate comparison

👉 Insight: High strike rate players significantly impact match results.

4. Bowling Analysis

Top wicket-takers

Economy rate comparison

👉 Insight: Economical bowlers play a key defensive role.

5. Venue Analysis

Venue-based performance trends

👉 Insight: Pitch conditions influence match strategy.

6. Match Outcome Analysis

Win by runs vs wickets

Margin analysis

👉 Insight: Close matches indicate competitive balance.
