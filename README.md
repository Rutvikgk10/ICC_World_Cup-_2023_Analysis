🏏 ICC Cricket World Cup 2023 – Data Analysis Project

📌 Problem Statement
The ICC Cricket World Cup 2023 generated vast amounts of match and player data. However, raw data alone does not provide meaningful insights for understanding performance, trends, and match outcomes.

This project focuses on analyzing World Cup data to uncover key insights about teams, players, and match-winning factors using data analytics techniques.

🎯 Objectives
Perform Exploratory Data Analysis (EDA) on World Cup data
Identify team and player performance trends
Analyze factors influencing match outcomes
Create visualizations for better understanding
Provide data-driven insights and recommendations

🗂️ Dataset Used
The analysis is based on the following datasets:
batting_summary.csv → Batsman performance (runs, balls, strike rate, boundaries, dismissals)
bowling_summary.csv → Bowler statistics (overs, wickets, economy, runs conceded)
match_schedule_results.csv → Match details (teams, venue, date, winner)
world_cup_players_info.csv → Player details (team, role, batting & bowling style)

🛠️ Tools & Technologies
Python
Pandas – Data cleaning & analysis
NumPy – Numerical operations
Matplotlib & Seaborn – Data visualization
Jupyter Notebook

📊 Analysis & Insights
🔹 Team Performance
Compared win ratios across teams
Identified most dominant teams
👉 Insight: Consistent teams maintain higher win percentages.

🔹 Toss Impact
Analyzed toss winner vs match winner
👉 Insight: Toss advantage is not always decisive.

🔹 Batting Analysis
Top run scorers
Strike rate comparison
👉 Insight: Players with higher strike rates significantly influence match results.

🔹 Bowling Analysis
Top wicket-takers
Economy rate comparison
👉 Insight: Economical bowlers help control matches effectively.

🔹 Venue Analysis
Performance across different stadiums
👉 Insight: Certain venues favor batting or bowling strategies.

🔹 Match Outcome Trends
Wins by runs vs wickets
Margin of victory
👉 Insight: Close matches indicate competitive balance, while large margins show dominance.

📈 Visualizations
The project includes:
Bar charts (team & player comparison)
Line charts (performance trends)
Heatmaps (correlation analysis)
Comparative plots
These help in clear storytelling and better decision-making.

💡 Key Insights
Balanced teams perform better than one-dimensional teams
Strike rate and economy rate are critical KPIs
Venue conditions impact match outcomes
Toss has limited impact compared to performance
